# Data Availability

This repository does not redistribute medical-image datasets.

The experimental pipeline uses **APTOS 2019 Blindness Detection** for primary model development and **Messidor-2** for external validation. Obtain each dataset from an authorized source and follow its license, access requirements, and terms of use.

Do not commit raw retinal images, dataset archives, credentials, personal data, or locally generated patient-linked files to this repository.
